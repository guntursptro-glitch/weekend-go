# WeekendGo

Aplikasi web untuk membantu menentukan tujuan weekend. Versi pertama fokus
pada kuliner di Depok, dengan pencarian berdasarkan kategori, area, dan kata kunci.

## Teknologi
HTML, CSS, JavaScript

## Status
## Status
Dalam pengembangan. Data awal mencakup 15 tempat makan di beberapa kecamatan Depok
(Beji dan Pancoran Mas paling lengkap). Harga dan alamat masih perlu diverifikasi.
